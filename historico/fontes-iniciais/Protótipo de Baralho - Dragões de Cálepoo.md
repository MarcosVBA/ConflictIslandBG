# Dragões de Cálepo

## Diretriz

- Possuem uma caverna, se protegerem ela, eles pontuam.
- Precisam se movimentar pelo mapa, cumprindo missões. Podem atravessar grande quantidade de regiões na movimentação.
- Possuem duas unidades apenas, um casal com a fêmea (10p de vida) e o macho (5p), converter dados de defesa em ataque para todos os conflitos
- Se voltarem para a caverna, recuperam vida. Se morrer, renasce, porem, perdem 4 pontos de vitória
