# Ideias

## Cartas de eventos

Ao atingir 20 pontos, puxar cartas do baralho de eventos até que a condição seja atendida, nesse caso, aplicar o efeito de fim de jogo.

| Nome | Condição | Efeito |
| ---- | ---- | ---- |
| Espalhar a Morte | Se um jogadores estiver jogando de necromante e ele não possuir a maior pontuação | Adicione um zumbi em cada região sem zumbies; O jogador com o necromante adiciona 2 zombies livremente em qualquer região |
| Vingança da mata |  Se um jogadores estiver jogando de elfos e ele não possuir a maior pontuação | Elimine quaisquer peça que não seja da facção de elfos das regiões de floresta, adicione 1 elfo em cada floresta |
| Riqueza Pirata | Se um jogadores estiver jogando de piratas e ele não possuir a maior pontuação  | O jogador de piratas adiciona livremente mais 2 bares no mapa, cada um gerando 1 ponto; A partir de agora, destruir os bares não gera penalidades a facção pirata, os piratas podem construir até 3 bares |
| Colonização | Se um jogadores estiver jogando de império e ele não possuir a maior pontuação | Construa quantas tecnologias quiser nas regiões; Adicione uma nova construção ainda não feita gratuitamente em qualquer região controlada |
| A Grande Fome | A facção do necromante não esta em jogo ou possui menos que 5 tropas | Todas as tropas, menos os zumbis, são eliminadas |
| Incendio na floresta | Se houver um jogador com os elfos | Cada jogador elimina uma peça qualquer que esteja em uma floresta; O jogador de elfos deve definir uma região para parar de produzir madeira |
| Escasses de ouro | Se não houver jogador com o império ou o império esta em 1ª ou 2ª posição de pontos | Apenas a região costa do Ouro Perdido (R11) continua produzindo ouro |
| O Mal da Guerra | Sempre | Quaisquer região com peças de mais de uma facção devem limpas, remover todas as peças. |
