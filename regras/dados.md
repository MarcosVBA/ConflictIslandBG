# Dados de combate

**Definido para teste; implementado.** Cada dado possui seis faces equiprováveis. Espadas representam dano ao defensor; cruzes representam dano ao atacante. A quantidade de dados e a aplicação de dano estão em [Combate](combate.md).

| Face | Ataque: cópias | Defesa: cópias |
| --- | ---: | ---: |
| Vazia | 3 | 1 |
| Uma espada | 1 | 1 |
| Uma cruz | 0 | 2 |
| Duas cruzes | 0 | 1 |
| Uma espada e uma cruz | 1 | 1 |
| Duas espadas e uma cruz | 1 | 0 |

Os dois tipos têm seis faces. O protótipo usa rolagens aleatórias sem semente reproduzível configurável.
